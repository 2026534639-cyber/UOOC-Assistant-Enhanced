# UOOC 助手

优课联盟（UOOC，uooc.net.cn）在线课程的浏览器辅助脚本，基于 Tampermonkey / 暴力猴运行。
作者：理不尽。适配新版页面，支持 DeepSeek / 硅基流动等常见大模型 API。

> ⚠️ **使用前必读**：UOOC 官方明令禁止刷课，违规可能导致视频进度被清零、账号封禁并通报学校。
> 本脚本并非无人值守挂机：提交试卷时若弹出「智能验证」（人机验证），脚本会自动暂停并提醒，
> **必须你本人在页面上手动完成验证**，之后脚本才会继续。是否使用请自行权衡风险，后果自负。

## 功能

- **播放辅助**：倍速两档选择器（2x / 2.25x，实测 2.5x 以上会被平台判无效观看并触发风控）、自动静音、自动播放，切换视频 3 秒内自动生效，无需刷新
- **一条龙全自动（🚀 全自动）**：看完自动连播下一个视频（等系统打勾才切换）；测验自动 AI 作答并提交；文本 / 附件自动跳过
- **AI 答题**：单选 / 多选 / 判断 / 填空 / 名词解释 / 问答 / 论述，调用大模型接口自动作答
- **图片题识别**：题目是图片时自动抓取图片发给视觉模型识别（已实测 Qwen3-VL 系列可用）
- **弹题自动作答**：视频中弹出的测验题自动提交，不挡播放
- **自动提交试卷**：填完答案后自动点「提交试卷」并确认（可在 UI 取消勾选改为仅填写）
- **遇人机验证自动暂停**：检测到智能验证时弹窗 + 系统通知提醒，本人完成后自动恢复
- **讨论不代发**：点「📋 复制题目」一键复制讨论题目，拿去问 DeepSeek 等任意 AI，把回答粘进回复框自己发表
- **全课程进度统计**：悬浮窗显示整个课程的视频 / 测验 / 讨论完成情况，每 60 秒刷新
- **未支持的题型自动跳过**，不会卡住流程

## 安装

1. 浏览器装好 [Tampermonkey](https://www.tampermonkey.net/)（Edge 可用「暴力猴」）扩展
2. 新建脚本，把 `UOOC_assistant.user.js` 的内容整份粘贴进去保存
3. 打开 UOOC 的课程学习页面，右上角出现 ⚙️ 和 📊 图标即安装成功

详细图文教程（含 API 配置与模型推荐）见 `脚本刷UOOC教程.docx`。

## 配置 AI 答题

点击页面上的 ⚙️ 图标，填入你自己的 API 地址和 Key（兼容 OpenAI 接口格式，
硅基流动 / DeepSeek 官方等均可）。不填 Key 时仅播放辅助和进度统计可用。
