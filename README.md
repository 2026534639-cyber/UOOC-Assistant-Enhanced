# UOOC 助手（增强维护版）

优课联盟（UOOC，uooc.net.cn）在线课程的浏览器辅助脚本，基于 Tampermonkey 运行。
在原作者脚本的基础上持续维护改进，适配新版页面与 DeepSeek / 硅基流动等常见大模型 API。

> ⚠️ **使用前必读**：UOOC 官方明令禁止刷课，违规可能导致视频进度被清零、账号封禁并通报学校。
> 本脚本不提供全自动挂机：遇到需要作答的检测题时需要你自己回答，答对才会解锁后续视频。
> 是否使用请自行权衡风险，后果自负。

## 功能

- **播放辅助**：2 倍速、自动静音、自动播放，视频结束自动进入下一个（仅限视频之间的切换）
- **AI 答题**：单选 / 多选 / 判断 / 填空 / 名词解释 / 问答 / 论述，调用大模型接口自动作答
- **图片题识别**：题目是图片时自动截图发给视觉模型识别（已实测 Qwen3-VL 系列可用）
- **弹题自动作答**：视频中弹出的测验题自动提交
- **全课程进度统计**：悬浮窗显示整个课程的视频 / 测验 / 讨论完成情况
- **未支持的题型自动跳过**，不会卡住流程

## 安装

1. 浏览器装好 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 新建脚本，把 `UOOC_assistant.user.js` 的内容整份粘贴进去保存
3. 打开 UOOC 的课程学习页面，右上角出现 ⚙️ 和 📊 图标即安装成功

详细图文教程（含 API 配置与模型推荐）见 `脚本刷UOOC教程.docx`。

## 配置 AI 答题

点击页面上的 ⚙️ 图标，填入你自己的 API 地址和 Key（兼容 OpenAI 接口格式，
硅基流动 / DeepSeek 官方等均可）。不填 Key 时仅播放辅助和进度统计可用。
